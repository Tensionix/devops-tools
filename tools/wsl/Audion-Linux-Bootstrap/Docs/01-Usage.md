# Usage

## Ubuntu

```bash
chmod +x bootstrap_ubuntu_minimal.sh bootstrap_ubuntu_power.sh
./bootstrap_ubuntu_minimal.sh
```

Or:

```bash
./bootstrap_ubuntu_power.sh
```

## Fedora

```bash
chmod +x bootstrap_fedora_minimal.sh bootstrap_fedora_power.sh
./bootstrap_fedora_minimal.sh
```

Or:

```bash
./bootstrap_fedora_power.sh
```

## What gets created

- CLI/dev packages for the distribution
- Python venv at `$HOME/.venvs/audion`
- Common Python libraries used in the toolkit workflow
