# Audion Linux Bootstrap

This archive contains Linux-side bootstrap scripts separated by family:

- `Ubuntu-Desktop`
- `Fedora-Desktop`

These scripts can be used inside WSL or on a native desktop install.

Profiles:

- `minimal` — smaller CLI/dev base
- `power` — expanded CLI/dev profile with extra tools

Each script creates the same Python virtual environment:

`$HOME/.venvs/audion`
