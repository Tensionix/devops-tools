# Audion DNS Doctor

Имена и значок сети на этой машине.

Две поломки выглядят как обрыв связи, хотя связь цела:

- **Имена не разрешаются.** Локальный резолвер (ControlD, YogaDNS, AdGuard,
  dnscrypt) прописал адаптерам `127.0.0.1` и перестал работать. Адреса
  пингуются, ни один сайт не открывается.
- **«Интернет как бы есть, но».** Служба `NlaSvc` остановлена — та, что
  проверяет выход наружу и рисует значок в трее. Сайты открываются, а Windows
  показывает глобус и не различает частную сеть с общественной.

## Запуск

| Файл | Что делает |
| --- | --- |
| `Run_Status.cmd` | смотрит и ничего не меняет |
| `Run_Repair.cmd` | поднимает лежачий резолвер или возвращает адреса роутера, потом чинит значок |
| `Run_Fix_Icon.cmd` | только значок: проба, автозапуск, служба |
| `Run_Use_Auto.cmd` | адреса от роутера по DHCP |
| `Run_Use_Router.cmd` | спрашивать шлюз напрямую |
| `Run_Use_Cloudflare.cmd` | `1.1.1.1`, `1.0.0.1` |
| `Run_Use_Google.cmd` | `8.8.8.8`, `8.8.4.4` |
| `Run_Use_Quad9.cmd` | `9.9.9.9`, `149.112.112.112` |
| `Run_Use_Yandex.cmd` | `77.88.8.8`, `77.88.8.1` |
| `Run_Use_AdGuard.cmd` | `94.140.14.14`, `94.140.15.15` |
| `Run_Help.cmd` | что делает каждый режим |

Все, кроме `Run_Status.cmd` и `Run_Help.cmd`, поднимают права сами: меняются
службы и адреса адаптеров.

## Что важно знать

Выбранного резолвера сперва спрашивают именем и прописывают, только если он
ответил: молчащий адрес оставил бы машину без имён.

Адаптеры туннелей (`WireGuard`, `AmneziaWG`, `TAP`, `OpenVPN`) не трогаются —
там DNS ставит сам туннель.

Снимок показывает не только адрес в поле «DNS», но и того, кто в итоге
спрашивает наружу, вместе с обратным именем: `dns.google`, `one.one.one.one`,
узел провайдера.

Подробности и порядок действий — в `docs\tools\DNS_DOCTOR_RU.md`.

## Движок

`system_core\Audion_Dns_Doctor.ps1`, ключ `-Mode`:
`Status`, `Repair`, `FixIcon`, `UseAuto`, `UseRouter`, `UseCloudflare`,
`UseGoogle`, `UseQuad9`, `UseYandex`, `UseAdGuard`, `Help`.

Вывод английский — как у остальных PowerShell-инструментов проекта, чтобы не
ловить кодировки в консолях CMD и PowerShell.
